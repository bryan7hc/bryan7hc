## 🚀 Proyectos Destacados

Aquí algunos de mis proyectos más relevantes, que reflejan mi experiencia técnica y mi capacidad para entregar soluciones útiles:

### **1. Chatbot de Finanzas — `chatbot_finanzas`**  
Un asistente conversacional diseñado para ayudar en la gestión financiera personal o empresarial. Funciona con procesamiento de lenguaje natural y puede realizar tareas como:

- Analizar y explicar reportes financieros.  
- Sugerir estrategias de ahorro o inversión.  
- Automatizar alertas de gastos e inversiones.

Este proyecto demuestra mi capacidad para integrar **IA/NLP** con lógica de negocio financiera.

---

### **2. Aplicación Móvil — `appMovil`**  
Una app móvil que refleja mi experiencia en desarrollo frontend + backend. Punto clave:

- Interfaz intuitiva para usuarios finales.  
- Comunicación con servidor backend para datos reales.  
- Integración con bases de datos para persistencia.

Con este proyecto, muestro cómo puedo construir productos cross-platform (o nativos) que realmente resuelven un problema.

---

### **3. Plataforma Automundo — `appAutoMundo`**  
Proyecto ambicioso: una plataforma de compraventa de autos:

- Panel administrativo para gestionar autos, usuarios, proveedores.  
- Autenticación con roles (cliente, proveedor, admin).  
- Sistema de reseñas y detalle de autos.  
- Arquitectura escalable para crecer con el negocio.

Este repo evidencia mis competencias en **arquitectura web**, **backend robusto** y **modelado de datos complejos**.
